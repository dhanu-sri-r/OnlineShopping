# 🛍️ Online Shopping Website

A basic **Online Shopping Website** created using **HTML**.
This project showcases some of the most popular shopping platforms such as **Amazon, Flipkart, Meesho, and Myntra**.

## 📌 About the Project

This project is a simple front-end web page designed to provide information about popular online shopping applications. It focuses on creating a clean and simple webpage using basic HTML concepts.

## 🛒 Shopping Platforms Featured

* 🛍️ Amazon
* 🛒 Flipkart
* 👗 Myntra
* 📦 Meesho
* 👕 Ajio
* 🛒 Max Fashions

## 🛠️ Technologies Used

* HTML5

## ✨ Features

* Simple and clean webpage design
* Information about popular shopping platforms
* Basic HTML structure and elements
* Easy-to-understand beginner-level project

## 🎯 Purpose

The main purpose of this project is to practice **HTML fundamentals** and understand how to structure a basic web page.

## 📂 Project Structure

```text
Online-Shopping/
│
└── index.html
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
